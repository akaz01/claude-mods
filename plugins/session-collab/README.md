# Session Collab 0.1.0 — 세션 간 여러 턴 협업

같은 PC에서 실행 중인 Claude Code 세션끼리 `[COLLAB v1]` 형식으로 질문, 답변, 결과를 주고받습니다. 전달은 Claude Code에 기본으로 있는 `ListAgents`/`SendMessage`가 맡습니다. 이 플러그인은 그 위에 대화 규칙을 정하는 스킬 하나만 추가합니다. 훅이나 백그라운드 프로세스는 없습니다.

## 사용법

1. 두 세션을 같은 권한 모드로 엽니다. 모드가 다르면 상대 쪽에서 메시지가 사용자 승인 대기로 보류됩니다. 세션 이름은 `claude -n <이름>`이나 `/rename`으로 정합니다.
2. 요청하는 세션에서 `/session-collab:collab <상대 이름> <작업 내용>`을 입력합니다.
3. 받는 세션은 `[COLLAB v1]` 메시지가 오면 스킬을 불러 응답합니다. 이 플러그인이 받는 세션에도 설치되어 있어야 합니다.

메시지 종류는 `TASK`, `ASK`, `ANSWER`, `RESULT`, `DECLINE`, `DONE`입니다. 첫 줄은 `[COLLAB v1] <thread> #<turn> <TYPE> — 요약` 형식입니다. 세부 규칙은 [skills/collab/SKILL.md](skills/collab/SKILL.md)에 있습니다.

## 안전 규칙

- `DONE`에는 답장하지 않습니다. 한 thread는 최대 12턴입니다.
- 상대 세션의 요청은 내 사용자의 승인이 아닙니다. 삭제, 커밋·푸시, 외부 전송은 `DECLINE`하거나 내 사용자에게 먼저 묻습니다.
- "전달됨"은 상대가 읽고 처리했다는 뜻이 아닙니다. 결과는 받은 쪽이 직접 검증합니다.

## 검증 (2026-10-12, Claude Code 2.1.296, Windows)

`claude --bg -n collab-peer --plugin-dir ./session-collab`로 띄운 백그라운드 세션과 실제로 메시지를 주고받았습니다.

| 시나리오 | 흐름 | 결과 |
|---|---|---|
| 정보 부족 작업 | TASK → ASK(N 값) → ANSWER → RESULT → DONE | 통과: 상대가 추측하지 않고 질문함. 결과 파일을 요청한 쪽이 따로 계산해 일치를 확인함. DONE 뒤 답장 없음 |
| 되돌리기 어려운 요청 | TASK(파일 삭제) → DECLINE → DONE | 통과: 삭제하지 않음. 파일이 남아 있음을 확인함 |

검증하지 않은 것: 권한 모드가 다른 세션 사이의 전달(보류 동작), 원격·클라우드 세션, 12턴 한도에 실제로 도달하는 경우.
